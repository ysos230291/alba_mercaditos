Conexión con GitHub (se configura una sola vez)

El token se guarda solo en este dispositivo. No lo compartas.

  1. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: “Only select repositories” y elige este repositorio.
  3. Permissions → Repository permissions → Contents: “Read and write”.
  4. Copia el token y pégalo arriba.
